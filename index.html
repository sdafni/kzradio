KZRadio Picker

Browse every show and episode of kzradio.net, with search, stars, random pick and track listings. The picker runs on top of kzradio.net itself, so it reads the site directly. Nothing is stored on any server.

Open the picker

Add it once per browser, in one of two ways:

1. Userscript (opens with one tap, recommended)

A userscript manager adds a ♫ button to every kzradio.net page.

  1. Computer: install Violentmonkey or Tampermonkey. In Chrome or Edge, also turn on Allow user scripts in the extension's Details page.
  2. iPhone / iPad: install the free Userscripts app, then turn it on in Settings → Apps → Safari → Extensions. Use it in Safari; Home Screen web apps do not run extensions.
  3. Android: use Firefox and add the Violentmonkey add-on.
Install userscript Open kzradio.net

2. Bookmarklet (no extension)

A bookmark that opens the picker when you tap it on kzradio.net.

  1. Computer: drag this button to your bookmarks bar: KZ Picker
  2. Phone: copy the code, bookmark any page, edit the bookmark, and paste the code as its address. On kzradio.net, open your bookmarks and tap it. In Chrome for Android, type the bookmark's name in the address bar and pick it.
